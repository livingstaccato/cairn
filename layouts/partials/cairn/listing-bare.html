{{- /* The autoindex. A table, no JavaScript, no interactive affordance — everything here survives lynx, w3m and a browser with scripting off. Same information architecture as the styled presenter: formats beside the path, the digest column header linking to the file that holds it, and the authored prose carrying its own provenance. Nothing under the listing. */ -}} {{- $c := .Params.cairn -}} {{- /* Entries come from the index.json resource in this page's bundle, not from frontmatter. Hugo refused any directory past roughly ten thousand entries while the listing rode in YAML — a decoder limit — and the same 50,000-entry directory renders from JSON in a third of a second. cairn writes that file, and Hugo publishes a bundle resource verbatim, so the JSON a reader fetches is the exact bytes cairn produced. Nothing is generated twice, which is where the earlier drift between the two came from. */ -}} {{- $r := .Resources.GetMatch "index.json" -}} {{- $entries := slice -}} {{- with $r }}{{ $entries = (. | transform.Unmarshal).entries }}{{ end -}} {{- /* The page renders at most max_rendered rows.
